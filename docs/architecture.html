Gemini Pro agent

PRIMARY
Rules engine
Deterministic 8-factor weighted model. Answers when the agent cannot, so the system degrades rather than fails
FALLBACK
Verdict store
Keyed to pilot + reading date. Reused for 2 hours, then re-evaluated. Invalidated by any data change
CACHE
↓Every verdict carries source — agent or rules — so a fallback is never shown as AI output

DECISION SUPPORT

Service separation. The API is private and reachable only by the dashboard's service account — pilot biometric and medical data is never on a public endpoint. The dashboard holds no decision logic.

Integrity boundary. No API endpoint can create or edit a biometric reading. Readings are the evidence behind a go/no-go call, and enter only through the ingestion pipeline.
